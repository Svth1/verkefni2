# Verkefni 1

## svar við spurningu 1
cd - Færa sig um skráarkerfid
ls - Sýnir lista af filunum sem eru á staðnum
pwd - Sýnir hvar maður er i kerfinu
mkdir - Býr til skrár og files

## svar við spurningu 2
git clone - Býr til copy af git repository 
git status - Sýnir núverandi stöðu vinnumöppunar og svæðið innan git geymslu
git diff - Ber saman breytingar milli utgafa af sama repositorykonni

## svar við spurningu 3
git log - Sýnir hvaða commands er búið að nota í fortíðini í þessu repository
git checkout - Þessi skipun skiptir núverandi grein yfir í aðra. Þetta uppfærir skrárnar í vinnuskránni þinni til að endurspegla stöðu greinarinnar 
git branch -notað til að stjórna greinum innan repositories. Það gerir kleift að búa til, skrá, endurnefna og eyða staðbundnum greinum
