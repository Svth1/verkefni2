# Verkefni 1

## svar við spurningu 1
cd - Færa sig um skráarkerfid
ls - Sýnir lista af filunum sem eru á staðnum
pwd - Sýnir hvar maður er i kerfinu
mkdir - Býr til skrár og files

## svar við spurningu 2
git clone - Býr til copy af git repository 
git status - Athugar stöðu staðbundinnar geymslu gegn fjartengdri geymslu
git diff - Ber saman breytingar milli utgafa af sama repositorykonni

## svar við spurningu 3
git log - Sýnir hvaða commands er búið að nota í fortíðini í þessu repository
git checkout - Þessi skipun skiptir núverandi grein yfir í aðra. Þetta uppfærir skrárnar í vinnuskránni þinni til að endurspegla stöðu greinarinnar 
git branch -notað til að stjórna greinum innan repositories. Það gerir kleift að búa til, skrá, endurnefna og eyða staðbundnum greinum
## svar við spurningu 4
Hvað er útgáfustýring - Kerfi sem heldur utan um breytingar, hver og hvenær þær voru gerðar, borið saman útgáfur af sömu skrá og gera kleyft við að vinna í teymi án þess að skrifa yfir vinnu aðra.
## svar við spurningu 5
Hverjir eru kostirnir á því að nota GIT - Ólíkt öðrum kerfum getur Git séð um útgáfustjórn án viðkomu gagnamiðils (server).
## svar við spurningu 6
Hversu oft telur þú að eigi að gera færslur (commit) í verkefni? - Frekar reglulega.
## svar við spurningu 7
Hvað er átt við með “Working Directory”?” og “Staging Area” í GIT? Það eru mismunandi stig í ferlinu að commita, Working directory er það sem maður byrjar á og eru skrárnar í tölvunni þinni og Staging Area er svona miðjan eiginlega þar sem maður setur dót áður en maður commitar það.
